Autorização para processamento externo

Na leitura automática, a imagem será enviada por um backend seguro ao serviço externo Azure AI Document Intelligence para extrair os dados do documento. Autorize o envio somente se concordar com esse processamento. Para continuar sem enviar uma imagem, preencha seus dados manualmente.
